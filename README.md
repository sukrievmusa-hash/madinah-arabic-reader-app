# Madinah Arabic Reader — Игра

Интерактивное приложение для запоминания арабских слов по учебнику **Madinah Arabic Reader (книга 1)**.

## Открыть

После включения GitHub Pages:
**https://sukrievmusa-hash.github.io/madinah-arabic-reader-app/**

Или скачайте `index.html` и откройте в браузере.

## Возможности

- Картинки из учебника
- Режимы: учить, квиз, слушай, да/нет, пары
- Аудио произношения
- Прогресс и «выученные» слова
- Настройки шрифта и автоперехода
- Один HTML-файл

- `index.html` — всё приложение
